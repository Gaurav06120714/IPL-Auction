# Player Photos

Drop a photo for any player here using the filename shown below.
Format: square-ish JPG (the card crops to a circle). PNG also works — just change the extension in player-card.tsx, or add .jpg copies.

If a file is missing, the card shows a clean category-tinted monogram instead, so partial coverage is fine.
